# FPL Analysis

Next.js-app (TypeScript, Tailwind, Recharts) for analyse av Fantasy Premier League. Ingen innlogging: du oppgir lag- eller liga-ID selv, og dataene hentes fra FPL-APIet (`fantasy.premierleague.com/api/`) via API-ruter i appen.

## Funksjoner

- Ligatabell med rangeringer
- Lagdetaljer: tropp, chip-bruk, målpoeng per runde
- Mest valgte kaptein og visekaptein

## Kom i gang

```bash
npm install
npm run dev
```

Åpne [http://localhost:3000](http://localhost:3000).
